# FingerGuider（ダンゴムシちょっかいアプリ）

マウスまたはカメラの人差し指で線を引き、3Dダンゴムシをインタラクティブに操作できる Web アプリ。

**デモ：** [https://shiny-sunset.github.io/FingerGuider/](https://shiny-sunset.github.io/FingerGuider/)

---

## 操作方法

### モード切り替え

画面右上の `🖱 マウスモード` / `☝ 指モード` ボタンで入力方法を切り替えます。

| モード          | 入力方法                                 |
| --------------- | ---------------------------------------- |
| 🖱 マウスモード | マウスドラッグで線を描画                 |
| ☝ 指モード      | 人差し指を立ててカメラに向けると線を描画 |

### ダンゴムシの数を調整

画面右上の `−` `＋` ボタンで 1〜10 匹の間で増減できます。

### モデルの切り替え

画面右上の ダンゴムシ / ちびキャラ ボタンで、ダンゴムシとちびキャラを切り替えられます。
ちびキャラは歩行・走り・丸まりのアニメーションと、シェイプキーによる表情（丸まり時は困った顔、食事中は笑顔など）に対応しています。

### プレビューウィンドウ

画面右下の小窓に、カーソルが最後に触れた個体を間近で表示します。
小窓の上でマウスホイールを回すと拡大・縮小できます。対象の個体にはアンバー色のリングが表示されます。

### 餌やり

| 入力                     | 操作                       |
| ------------------------ | -------------------------- |
| マウス                   | 右クリックで餌を1個配置    |
| 指（✌️ ピース / Victory） | 人差し指の先端に餌を1個配置 |

餌を置くと、近くのダンゴムシが寄ってきて食べます（線で追われているときは餌より逃げを優先）。

### ダンゴムシの反応

| 操作                   | 反応                           |
| ---------------------- | ------------------------------ |
| ダンゴムシが線を近づく | 逃げる方向に進路変更           |
| ダンゴムシが線に接触   | ダンゴムシがまるまる           |
| 線が消えたあと         | ダンゴムシが伸びた後に歩き出す |
| ダンゴムシ同士が接近   | お互いに反発して避け合う       |
| 近くに餌がある         | 餌に寄っていき、食べて餌が縮小・消滅 |
| 線はフェードアウト     | —                              |

### 指モードのジェスチャー

| ジェスチャー                    | 効果                           |
| ------------------------------- | ------------------------------ |
| 人差し指を立てる（Pointing_Up） | 線を描画・指先が赤丸で強調表示 |
| ✌️ ピース（Victory）            | 人差し指の先端に餌を配置       |
| それ以外（グー・パーなど）      | 描画停止                       |

## 虫食いモード

タイトル画面の `虫食いモード` から起動します。カメラ映像を全画面に流し、顔検知と写真加工で遊ぶモードです。

| フェーズ | 内容 |
| -------- | ---- |
| ライブ   | カメラ映像に映った**人の顔にダンゴムシが群がってくる**（MediaPipe FaceDetector で顔を検知） |
| 撮影     | 📷 ボタンで、群がっていたダンゴムシを消して**静止画をキャプチャ** |
| 虫食い   | 顔の楕円全体に敷いた**見えない餌**へダンゴムシが集まり、餌を食べながら**顔全体に穴を空ける** |
| 完成     | **顔の餌を食べ終えたら**ちびキャラのドヤ顔を写真に合成 |
| 保存     | **ダウンロード**（透過 PNG）／**戻る** を選ぶとライブモードへ復帰 |

- カメラはインタラクションモードと同じストリームを共有します。
- 顔が検出できないまま 📷 を押した場合はヒントを表示し、撮影しません。
- 虫食いの完成は時間ではなく「餌を食べ終えた割合」で判定します。

### 差し替え可能な画像アセット（`public/` に置くと自動使用）

| ファイル | 用途 |
| -------- | ---- |
| `cutin_start.png` | 撮影直後のカットイン画像 |
| `chibi_pose.png` | 完成写真に載せるちびキャラ（ドヤ顔＋ピース） |

各種調整値（餌の密度・食べ速度・完成割合・ちびキャラの表示位置/大きさ・**ダンゴムシの大きさ `DANGO_SIZE`**）は `src/insectMode.js` 冒頭の定数で変更できます。`DANGO_SIZE` は虫食いモード専用で、大きさに合わせて**反発距離・移動速度・虫食い穴の大きさも連動**します（インタラクションモードには影響しません）。

## 描画スタイル（トゥーン＋DS風ドット）

プロジェクト全体に、セル調のトゥーンシェーダーと ピクセル化シェーダーを適用しています。設定は `src/renderConfig.js` の 2 つの定数で切り替えます。

| 設定 | 内容 |
| ---- | ---- |
| `TOON` | 3D モデル（ダンゴムシ／ちびキャラ）を `MeshToonMaterial`（3 段階の階調）で描画。`false` で通常マテリアルに戻る |
| `PIXEL_SIZE` | 1 ブロックの一辺（px）。大きいほど荒くなる。**1 以上でピクセル化オン**、**1 未満でオフ** |

- ピクセル化は **3D・2D（背景/線/餌/写真/穴）・カメラ映像**すべてに同じグリッドで適用し、合成結果が均一なドット絵になります。
- 3D は低解像度バッファ＋ニアレスト拡大、2D は各フレームを縮小→ニアレスト拡大でブロック化。ダウンロードする虫食い写真にも同じドット化がかかります。
- ワールド座標は原寸のままなので、当たり判定や配置はピクセル化の有無で変わりません。

## 起動方法

```bash
npm install
npm run dev
```

ブラウザで `http://localhost:5173` を開く。

## 技術スタック

| 技術                                                                                                  | 用途                                   |
| ----------------------------------------------------------------------------------------------------- | -------------------------------------- |
| [Vite](https://vitejs.dev/)                                                                           | ビルドツール                           |
| Vanilla JavaScript（ES Modules）                                                                      | アプリロジック全般                     |
| Canvas 2D API                                                                                         | 背景・線・手のスケルトン描画           |
| [Three.js](https://threejs.org/)                                                                      | 3D モデルのレンダリング・トゥーンシェーダー・低解像度ピクセル化 |
| [MediaPipe Tasks Vision](https://developers.google.com/mediapipe/solutions/vision/gesture_recognizer) | ジェスチャー認識・手のランドマーク検出・顔検知（FaceDetector） |

## ファイル構成

```
FingerGuider/
├── index.html
├── style.css
├── vite.config.js
├── model/
│   ├── dangomushi.glb        # ダンゴムシ 3D モデル
│   └── DangoGirl.glb         # ちびキャラ 3D モデル（アニメ・表情入り）
└── src/
    ├── main.js               # エントリポイント・イベント管理・画面遷移
    ├── character.js          # Isopod クラス（物理・ステートマシン・餌判定・顔誘引）
    ├── line.js               # 描画線の管理・距離判定
    ├── food.js               # 餌（Food クラス）
    ├── handInput.js          # MediaPipe ジェスチャー認識ラッパー
    ├── faceInput.js          # MediaPipe FaceDetector ラッパー（顔検知）
    ├── insectMode.js         # 虫食いモード（ライブ→撮影→虫食い演出→DL）
    ├── renderConfig.js       # 描画スタイル設定（トゥーン ON/OFF・ピクセル粗さ）
    ├── pixelate.js           # 2D キャンバスをドット化するユーティリティ
    ├── renderer.js           # Canvas 2D 描画（線・餌・選択リング）
    └── isopodRenderer3D.js   # Three.js 3D レンダラー（モデル切替・アニメ・表情・プレビュー・トゥーン・ピクセル化）
```

（`public/blaze_face_short_range.tflite` … 顔検出モデル）
